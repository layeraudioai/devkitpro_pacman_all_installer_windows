# devkitpro_pacman_all_installer_windows
install all devkitpro &amp; msys2 pacman packages entirely automated

1: open the exe and go through the prompts
-
2: install devkitpro patiently without spam clicking or panicking if terminals open
-
3: click finish in the devkit pro installer
-
4: patiently wait while the terminal installs all packages through pacman this will take a while
-
5: done.
